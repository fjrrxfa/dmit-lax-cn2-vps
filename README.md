## 洛杉矶CN2 VPS 的三条线路：Pro、EB、T1 差在哪

三条线的差别在回程路由上，配置表反而看不出多少。

**LAX.Pro** 是旗舰线。电信、联通去程走 CN2 GIA，移动去程走 CMI，三网回程全部 CN2 GIA。国内访问的延迟和晚高峰稳定性，三条线里它最好。

**LAX.EB** 是中国优化里的第二档。电信走 AS9929 / AS58807 负载均衡，联通 AS9929，移动 AS58807，也就是常说的 CMIN2。日常刷网页、开后台，和 Pro 的差距不算大；晚高峰一挤，差距就出来了。

**LAX.T1** 走 Telia、Zayo、Cogent 这类国际路由，完全没有中国大陆方向优化。它的价值在于便宜和带宽足，适合访客全在海外的站点。

CN2 GIA 到底贵在哪，值得单独说一句。它是中国电信 CN2 骨干网里的高优先级产品，号段 AS4809，和普通 163 线路（AS4134）、CN2 GT 的区别在路由上：GIA 的去程和回程都走优化通道，不跟普通互联网流量挤在一起。落到体感上，普通线路晚高峰延迟能冲到 300ms 以上、丢包超过 10%，CN2 GIA 通常还能稳在 150ms 上下，丢包接近 0。

洛杉矶是中美海缆的主要登陆点之一，电信、联通、移动都在这里有直连优化线路，回程路由比圣何塞、西雅图这些机房短，国内访问延迟第三方测评普遍落在 150–180ms 区间。各家测试的节点和时间不同，别把某一个精确数值当标准。

## 常见问题

**Pro 和 EB 建站，体感差别有多大？**
电信用户差别明显，Pro 走 CN2 GIA 回程，延迟和稳定性都在 EB 之上，晚高峰差距拉得更开。联通和移动用户差别小一些，EB 的 CMIN2 / 9929 对这两个运营商已经够用，预算有限选 EB 是合理妥协。

**IP 被封了怎么办？**
Pro 和 EB 系列每 15 天可以免费申请换一次，前提是 IP 被墙，联系客服操作；其他情况换 IP 收 $5。

**适合跑 WordPress 吗？**
适合。装宝塔面板后配 LNMP（Linux + Nginx + MySQL + PHP），WordPress 装完就能用。系统默认是 SSH 密钥登录，不是用户名密码，后台可以改成密码登录。

**建站要不要另外套 CDN？**
纯文字、流量不大的站，CN2 GIA 直连国内够用，不需要 CDN。图片多、视频多，或者想让国内访问接近国内 CDN 节点的体验，可以叠一层 CDN，DMIT 当回源站。

**Pro.TINY 一直缺货怎么办？**
两条路：盯着官网等补货，或者直接买 Pro.Pocket，$14.9/月，带宽和硬盘都升一档。

**流量用完了会停机吗？**
不会。Pro 和 EB 降速到 4–10Mbps 继续跑，T1 限速 100–500Mbps。

**支持哪些付款方式？**
支付宝、微信、PayPal。
